Drive the bundled Frida on this rooted phone: check its status, start or stop frida-server, or inject a one-shot JavaScript script into a process. The Frida binaries ship inside Mika and deploy to /data/local/tmp on first use, running as root through su. Parameters: action is one of "status", "start", "stop", "inject". "inject" also needs target (process name such as com.example.app, or numeric PID) and script (Frida JavaScript source, up to 200000 characters); the script runs once and its console.log output comes back in stdout along with exitCode, timedOut and durationMs; timeoutSec defaults to 30, at most 600. "start" accepts force (default false) to restart a running server. start and inject may first ask the user, showing what will run; status and stop run directly.
